JSON Schema export and generated Swift package (`PixerateSchemas`).

- **JSON Schema export**: `npm run export:json-schema` (run by `npm run build`) writes every schema to `json-schema/<module>/<Name>.json` with an index `json-schema/index.json`, shipped in the npm package (`./json-schema/*`). A schema used inside another one is a `$ref` to its own definition. Defaults computed at parse time (such as `createdAt`) are left out. Also adds the `./common` export.
- **Swift package**: a root `Package.swift` with the `PixerateSchemas` library (macOS 13+, iOS 16+, Foundation only), generated by `npm run gen:swift` for the `common`, `jazz` and `agent` modules. Shared schemas are shared Swift types, nullable fields are typed optionals, defaults match Zod's, and `swift/GENERATED.md` lists anything the generator could not type. Swift consumers depend on the npm release tags (`from: "1.45.0"`).
- **Checks**: CI fails when `json-schema/` or the generated Swift is stale. Swift tests decode fixtures written by Zod, encode them again and compare with the original JSON.
